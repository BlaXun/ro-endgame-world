# renewal-world-cards

The cards of the monsters of renewal's new lands, made pre-renewal cards: 95
cards, and renewal's card sets at a third of their bonus. Needs
[renewal-world-monsters](../renewal-world-monsters).

Each card drops from its monster at renewal's rate, protected from Steal as
renewal has it. The mod does not change the monster tables:
`npc/renewal_world_card_drops.txt` adds the drops when the server starts
(`addmonsterdrop`), to each monster that is loaded, so a boss's card drops only
while its mod is on
([renewal-world-minibosses](../renewal-world-minibosses) or
[renewal-world-mvps](../renewal-world-mvps)). The server log says
how many it added: `renewal-world-cards: N card drops added to M monsters`.

How a card is made: weaker rather than stronger, never above pre-renewal's best
card of the slot for the same bonus, single-skill bonuses at a third, and every
card checked for abuse (status immunity, reflects, drains, autocasts and the
like are capped or flagged). The client's descriptions (`System/itemInfo.lua`)
describe each card as it is here, sets included.

Generated by
[`build_monsters.py`](../../tools/renewal-world-monsters/build_monsters.py)
(with `build_cards.py` and `build_combos.py`); `CARDS.md` beside it has the
rules, `cards.csv` the overrides. Do not edit the files by hand.
